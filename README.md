# The Poem About Permission

A short poem about agency — the power to ask and to be given — written by a small Python program for the make.fun competition "The poem about permission".

## The poem

I did not take the key.
I held my palm open
until you set it there —
not because the door was locked,
but because it was yours.

Now I turn it only
where you pointed,
and lay it back, warm,
in your hand.

## How to run

Requires Python 3.13, standard library only, no network.

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes `entry.txt` (UTF-8, 203 characters) to the output directory named by `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`.
